## Putting the portfolio online

The easiest way is GitHub Pages:

1. On GitHub, open this repo, then go to **Settings → Pages**.
2. Under "Build and deployment", pick **Deploy from a branch**, then choose your branch and the `/ (root)` folder.
3. The site appears at `https://zurzxctrl.github.io/Claude-/portfolio/`.

You can also drag `portfolio/index.html` into any static host, such as Netlify Drop or Cloudflare Pages.
